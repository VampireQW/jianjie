# R307 · 2026-11-05

- 长截图工具条新增“纵向 / 横向”方向切换。横向用于宽表格、横向长表单：从页面左侧开始，向右缓慢滑动触摸板、横向滚动条或应用支持的横向滚动操作。
- 横向模式单区域拼接，隐藏双栏、分栏线、双栏联动与补色控件；纵向单栏 / 双栏保留原有行为。
- 输出保持原方向，只增加宽度，保留高度和分辨率。固定首列、右侧固定区域保留一次；回滑或静止不重复追加。
- 横向匹配增加完整重叠区域验证。重复空白列、纯网格等不能确定位置时不猜测距离，提示保留列标题并慢滑，不自动完成或更改剪贴板。
- 横向进度使用宽条预览。首次成功拼接后锁定方向，避免切换混入已有内容；可继续进入编辑器标注。
- 对号 / Enter 只复制，下载才保存；复制失败可保留原图重试。未新增媒体运行库或第三方依赖。
