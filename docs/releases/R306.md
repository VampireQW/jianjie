# R306

- 修复高分辨率 60 fps 录屏卡顿：桌面画面改走 DXGI 与 GPU 内部处理链路，减少整屏读回和软件色彩转换。
- 移除落后后反复编码同一帧的补帧循环；按有效录制时间和帧周期生成时间戳，暂停时间不进入成片。
- 编码器、桌面采集与 COM 资源统一由录制线程创建和释放；旧驱动保留兼容回退。录制异常明确显示，避免静默生成停帧视频。
- 保留 30 / 40 / 50 / 60 fps、指针、点击高亮、选区拖动和缩放。对号与 Enter 仍只复制，下载按钮才保存到指定目录。
- 仅新增小型系统接口 DLL，不附加媒体运行库。

本次公开更新同时包含 R304 / R305 的双栏长截图联动滚动：可用鼠标滚轮或触摸板双指滑动带动另一栏，默认关闭，开启链条图标后生效；关闭后可独立校正，两栏继续各自拼接。
