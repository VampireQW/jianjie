# R302 · 2026-11-02

- 优化“今日 TODO”和“待办清单”的来回切换：分别复用页面与任务行，不再每次销毁并重新创建整组控件，两页各自保留滚动位置。
- 点击切页时先更新界面，当前页等窗口状态沿用 500 毫秒防抖保存。任务新增、修改与 MCP 写入仍保留原有的保存确认流程。
- 编辑中的任务可在切页时提交；未结束的勾选过渡会先提交，任务变更与跨日后会刷新缓存，避免显示过期分组。
- 仅保留一个闲置页，闲置页超过 128 个任务行时释放，隐藏窗口也释放闲置页；不增加后台进程或第三方依赖。

验证：77 项任务、提醒与 MCP 相关测试通过。同为 6 项今日任务、94 项待办的独立演示数据，16 次交替切换的绘制中位耗时由约 129 毫秒降至约 10 毫秒；首次进入页面仍需创建任务行。这是本机原生 Qt 样例测量，包含同等性能采样开销，不代表所有设备与任务规模的响应时间。
