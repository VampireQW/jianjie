# R310 · 2026-11-10

本次公开发布合并 R309 与 R310 的横向长截图修复。程序构建于 2026-11-06，已通过原网页实测反馈。

- 改善带固定列的宽表格兼容性，避免鼠标行高亮、固定列阴影和重复网格干扰拼接。
- 清理接缝处重复的固定列阴影，较大的固定顶部、底部内容保留一次。

- 长截图直接抓取所选区域，避免每次读取整屏；保留混合缩放、负坐标显示器上的像素坐标精度。
- 横向模式提高采样频率，切回纵向恢复原节拍，减少快速滚动造成的重叠丢失。
- 修复网页只改变行背景色时，冻结列被误判为移动的问题。
- 修复表头与正文分开滚动、画面更新短暂不同步后一直无法继续拼接的问题；最多保留两份备用参照，按累计位移恢复，避免重复追加。
- 表头补齐但正文未继续移动时，刷新顶部画面而不增加图片宽度。
- 在局部匹配中补上静止候选，避免鼠标或高亮变化产生假的 1 像素追加。
- 无法接上时明确提示向左退回上一段再继续，不猜测缺失内容，不自动复制未完成的长图。

保留横向上方预览、方向锁、复制 / 下载，以及纵向双栏与联动滚动；横向模式仍只拼接单个区域。未增加新的图像识别依赖。

完整版为单个 EXE，40,556,164 字节（约 40.6 MB）。配套提供 `AirPlay-source.zip` 和 `SHA256SUMS.txt`。
