# R304 · 2026-11-03

- 双栏长截图新增“联动滚动”开关（链条图标），默认关闭。开启后，在任意一栏使用纵向鼠标滚轮，另一栏同方向跟随。
- 关闭联动可分别校正位置，再重新开启；一栏到底后不阻止另一栏继续滚动，两栏仍各自匹配并拼接。
- 仅联动选区内两个原有窗口，不移动光标、不改变焦点；选区外滚动、Ctrl/Shift/Alt+滚轮、鼠标按键拖动和水平滚轮不转发。
- 补色面板、取色器打开时暂停联动，关闭后恢复；切回单栏、完成、取消、编辑或隐藏捕获窗口后停止转发，结束会话移除监听。
- 使用 Windows 原始鼠标输入和窗口消息，复用现有双栏拼接，不新增依赖或常驻进程。

联动用于两块可独立滚动的内容，只同步滚轮动作，不自动对齐两份文档的段落。不同应用的滚动速度、页面结构和新增内容仍可能造成错位；拖动滚动条、键盘翻页不联动。更高权限运行的目标窗口可能拒绝消息，软件不会自动提升权限。
