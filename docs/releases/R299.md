# R299 · 今日待办轻提醒

主面板“设置”增加“今日待办轻提醒”，默认关闭。可设置约半小时、约一小时、约两小时的提醒频率及当天提醒时段；默认 09:00–18:00，间隔自动错开，每日最多六次。今日范围与任务窗口一致，包含此前未完成的计划任务。

提醒卡片展示未完成数量与最多两项任务，优先高优先级，同优先级轮换。支持查看今日任务、30 分钟后提醒、关闭本次、今天不再提醒及进入提醒设置；默认十秒收起，悬停暂停，不抢输入焦点，位置复用全局 Toast 四角设置。

首次等待十分钟。查看任务后重新安排间隔；截图、录屏、锁屏及其他通知出现时暂缓。单条任务的精确提醒优先，轻提醒至少延后十五分钟。休眠后的延迟触发不补弹积压提醒；任务全部完成时收起卡片并停止计时。

频率、时段和开关沿用 settings.json；当天次数、下一次时间及今日暂停状态保存在任务数据的 win.today_nudge 中，随应用数据迁移，重启不清零。提醒状态不修改任务版本号。关闭功能或没有今日任务时停止轻提醒定时器，没有新增常驻进程或第三方依赖。

验证覆盖调度规则、范围筛选、每日上限、跨日、重启恢复、休眠延后、暂停、四角定位、完成后收起、保存失败保护及原有任务/MCP 功能；另使用隔离示例数据在真实 Windows 窗口验证排版、焦点、设置回退、MCP 刷新与窗口联动。
