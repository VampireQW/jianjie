# R305 · 2026-11-03

- 双栏长截图的“联动滚动”增加触摸板双指上下滚动支持，继续支持普通鼠标滚轮。
- 统一接收 Windows 系统滚轮消息，不再只依赖原始鼠标报告；小于一格的连续滚动增量按原顺序保留，不取整、不叠加两套监听，避免触摸板丢小步进或重复滚动。
- 监听回调只接收滚动事件，原始输入继续交给当前窗口；向另一栏的转发延后处理，不移动指针、不抢焦点。
- 关闭联动、切换单栏、打开补色或取色面板、完成和取消时，停止接收并清除旧会话中尚未转发的事件。
- 仍需两侧各自具有可独立滚动的内容；一侧到底后另一侧可以继续，文档段落长度不同时可关闭联动单独校正。

验证：51 项长截图相关测试通过。已采集用户当前触摸板在 Word 中的双指滚动事件，并由用户在独立双栏示例窗口确认“左右两栏都能一起滚动”。系统窗口转发、到底继续及监听开关清理通过验证；尚未逐个覆盖所有触摸板驱动或 Office 版本。
