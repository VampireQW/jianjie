# R314 · 2026-11-17

- 截图文字新增底色选项，默认无底色，可随时恢复透明。
- 底色与文字共用红、橙、绿、蓝、白、黑六种预设色，也可选择自定义颜色。
- 底色四角带圆角。选择白色底色时自动配黑字，其他底色配白字，文字颜色可继续手动调整。
- 输入预览、普通截图、长图编辑与美化、历史再编辑和导出使用相同效果。撤销可同时恢复底色和自动调整的字色。

文字工具的颜色选项旁新增「底色」入口。选色时可以继续保留正在编辑的文字。

Windows 完整版为单个 EXE，约 40.6 MB（40,569,987 字节）。Release 同时提供投屏组件源码和 SHA-256 校验文件。
