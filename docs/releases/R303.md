# R303 · 2026-11-03

- iPhone 投屏新增“声音输出”选择，支持跟随 Windows 系统默认，或指定显示器、扬声器、耳机等可用播放设备。
- 记住上次选择。连接前检查设备；设备未连接时回退到系统默认，并保留原选择，方便下次重新连接设备后复用。
- 设备列表在后台读取，支持手动刷新；投屏连接期间锁定选择，断开后可切换，下次连接生效。
- 继续复用现有 AirPlay 和 Windows WASAPI 播放组件，不新增媒体运行库或常驻进程。
- 包含 R302 的任务切换优化：“今日 TODO”和“待办清单”复用页面与任务行，各自保留滚动位置，闲置缓存有上限。详见 [R302](R302.md)。

验证：128 项相关回归测试通过，其中 14 项覆盖声音输出选择，77 项覆盖任务、提醒及 MCP；默认输出、显示器音频及 Realtek 扬声器均通过独立静音播放验证。实际 iPhone 音乐/视频的听音结果仍需连接手机确认。

Windows 64 位全量单文件包：40,440,990 字节（约 40.4 MB），比 R302 增加 12,214 字节。
