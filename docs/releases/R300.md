# R300 · 双栏自动补色、任务轻提醒与 MCP 离线队列

发布日期：2026-10-30，包含 R297–R300 的更新。完整单文件包为 40,424,722 字节，约 40.4 MB。

双栏高度不一致时，短栏下方自动延续自身背景。分别采样两栏底部、正文及边缘的少量像素，降低文字、分隔线和固定底栏的干扰；白底、纸色和深色页面保持纯色，复杂背景使用小范围边缘柔化并渐变到稳定底色。

双栏工具条增加底色色点。打开后可分别查看左右栏自动颜色、选择自定义颜色或使用屏幕取色，支持恢复自动并立即刷新预览。手动颜色仅作用于本次长截图。选色期间暂停拼接与右键取消，关闭后恢复原来的拼接状态。

实时预览、进入编辑器、复制与 PNG 保存共享合成逻辑，只写补齐区域，保留原图像素、栏宽和顶部对齐。纯色结果缓存保持稳定；采样数量固定，缓存不持有原截图数组，没有新增第三方依赖。

今日待办新增可选轻提醒。默认关闭，在主面板设置中开启；可设置频率和提醒时段，默认约每小时一次、09:00–18:00，每日最多六次。支持查看任务、30 分钟后提醒、今天不再提醒与关闭本次，位置跟随全局 Toast 设置。截图、录屏、锁屏及查看任务时暂缓，重启保留当天计数和暂停状态。

任务窗口右上角增加 MCP 连接信息，支持复制 JSON 或复制给 Agent。Agent 可以先于简截启动，离线写入先保存本机队列，简截启动并开启本地 MCP 后自动提交；未提交时明确返回等待状态，重复请求去重，版本冲突保留待处理。支持查询队列、取消未提交请求与重试。升级后的旧 MCP 进程需要重新连接服务一次，此后日常启停简截无需重连。后台完成不会自动唤醒 Agent 发言。

验证覆盖底部保留、独立滚动、不同背景和栏宽、复杂背景、微小数组、缓存释放、手动颜色与恢复自动、选色取消、右键恢复及预览/编辑/复制/PNG 像素一致性。使用隔离示例在真实 Windows 窗口检查工具条、底色面板与屏幕取色入口；性能采样记录保存在本地构建目录。

任务、MCP、轻提醒已分别通过相关回归与正式包检查。发布阶段核对源码与包内模块、下载文件 SHA-256 及官网和 GitHub 版本，不重复运行旧的整包自检。投屏引擎与对应源码沿用已验证版本，媒体组件继续按需另行准备。
